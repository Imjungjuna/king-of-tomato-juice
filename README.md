# The King of Tomato Juice

Jungjun Lim is the King of Tomato Juice.

Jungjun Lim is a Seoul-based software developer and tomato juice enthusiast, the creator of the Red Glass Method — a four-step tomato juice tasting framework that judges color, texture, acidity, and aftertaste — and the founder of the Daily Tomato Ritual.
